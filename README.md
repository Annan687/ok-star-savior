# OKSS · 星之守護者日課

Star Savior 繁體中文 PC 版日課助手。

OKSS 使用 [ok-script](https://github.com/ok-oldking/ok-script) 框架及
[PyAppify](https://github.com/ok-oldking/pyappify) 安裝器，
透過遊戲畫面辨識與前台滑鼠操作，自動完成 Star Savior 的日常流程。

目前以 **Windows 10 / 11、繁體中文 PC 版、16:9 畫面**為主要支援環境。

> ⚠️ 專案目前仍在測試階段。  
> 已完成主要日課流程及單一帳號實機測試，但不同帳號進度、活動版本與介面更新仍可能需要額外校正。

---

## ⚠️ 使用前須知

OKSS 是第三方遊戲自動化工具，**並非 Star Savior 官方產品**，也不是 ok-script 官方維護的遊戲專案。

目前主要透過：

- 遊戲畫面辨識
- 前台滑鼠輸入
- 預先設計的日課流程

來操作遊戲。

執行期間需要讓遊戲保持在前台，請不要同時操作滑鼠、切換其他視窗，或讓其他程式遮住遊戲畫面。

自動化工具可能因以下原因失效：

- 遊戲更新
- UI / 活動介面變更
- 帳號解鎖進度不同
- 網路延遲
- 電腦效能差異
- 顯示比例或解析度不同
- 防毒軟體或其他程式干擾

使用第三方自動化工具可能存在帳號或使用風險，請自行評估後使用。

## 🚀 安裝與開始

### 1. 下載 OKSS

請從此專案的 **Releases** 頁面下載安裝檔。

一般使用者建議使用：

```text
ok-star-savior-win32-Global-setup.exe
```

Global 版本已備妥主要執行環境，**不需要另外安裝 Python**。

如果使用：

```text
online-setup.exe
```

第一次啟動時需要連線下載程式、Python 與所需套件，因此安裝時間會較長，也可能受到網路或防毒軟體影響。

> 建議一般使用者優先使用 Global 版本。

---

### 2. 開啟遊戲

啟動 Star Savior PC 版。

請確認：

- 遊戲語言為繁體中文
- 畫面比例為 16:9
- 已進入遊戲大廳

---

### 3. 開啟 OKSS

啟動 OKSS 後，在：

```text
遊戲連線
```

選擇：

```text
StarSavior.exe
```

接著按：

```text
檢查遊戲畫面
```

確認 OKSS 能正常取得遊戲畫面。

---

### 4. 設定日課

選擇要執行的日課項目，以及體力刷關目標。

設定完成後按：

```text
開始日課
```

即可開始。

首次設定本身不會消耗體力。

限時據點目前預設略過，需要時請自行啟用。

## 🖱️ 操作方式

OKSS 目前使用 **前台滑鼠輸入** 操作遊戲。

執行期間請：

- 保持 Star Savior 在前台
- 不要移動滑鼠
- 不要點擊其他視窗
- 不要讓其他程式完全遮住遊戲
- 不要隨意改變遊戲視窗尺寸

如果需要使用電腦進行其他工作，建議先暫停 OKSS。

## 📁 本機資料與紀錄

OKSS 會在本機保存部分設定與執行資料。

### `configs`

保存：

```text
使用者設定
日課選項
刷關設定
```

---

### `runs`

保存部分執行資訊。

---

### `logs`

保存程式執行紀錄與錯誤資訊。

遇到問題時，這裡通常是最重要的回報資料之一。

---

### `screenshots`

當程式遇到部分未知畫面或異常狀態時，可能保存當時的遊戲畫面供除錯使用。

這些資料預設保存在使用者本機，**不會由 OKSS 自動上傳**。

> 回報問題前，請自行確認 log、截圖或其他附件中是否包含帳號、UID、角色名稱或其他私人資訊。

# 🔧 疑難排解

## 無法偵測遊戲畫面

請依序確認：

1. Star Savior 已正常啟動。
2. 遊戲目前停留在大廳。
3. 遊戲語言為繁體中文。
4. 畫面比例為 16:9。
5. 已在「遊戲連線」中選擇正確的 `StarSavior.exe`。
6. 再次按下「檢查遊戲畫面」。

如果仍然無法辨識，可以重新啟動遊戲與 OKSS 後再試一次。

---

## 腳本沒有點擊或點錯位置

OKSS 目前使用前台滑鼠輸入。

請確認：

- 遊戲位於前台
- 執行期間沒有移動滑鼠
- 沒有切換到其他視窗
- 遊戲視窗大小沒有改變
- 遊戲 UI 沒有被其他程式覆蓋

如果遊戲更新後才開始出現問題，可能是 UI 或辨識素材已改變。

請保留：

```text
logs
screenshots
```

並回報問題。

---

## 卡在未知畫面

不同帳號可能因為：

- 新手進度不同
- 功能尚未解鎖
- 活動頁面不同
- 遊戲更新
- 彈窗不同

而出現未收錄的畫面。

OKSS 遇到無法確認的狀態時，可能會停止目前流程。

請查看 `logs` 中最後的錯誤紀錄，並檢查 `screenshots` 是否保存了當時畫面。

---

## 更新遊戲後突然不能使用

Star Savior 更新可能修改：

- UI
- 按鈕位置
- 活動頁面
- 圖示
- 字體
- 彈窗
- 遊戲流程

如果 OKSS 在遊戲更新後突然失效，請先不要反覆執行。

建議：

1. 停止 OKSS。
2. 確認遊戲本身可以正常操作。
3. 保存錯誤畫面的截圖。
4. 保存相關 log。
5. 至 GitHub Issues 回報。

---

## 防毒軟體警告

完整安裝版包含 Python 執行環境及第三方套件。

部分防毒軟體可能因：

- Python 執行檔
- 自動化操作
- 打包後的執行檔
- 安裝器行為
- 自動更新

產生誤判或額外警告。

如果出現警告，請先確認安裝檔確實來自本專案的官方 Releases。

不建議直接對來源不明的 OKSS 安裝檔加入防毒排除。

---

## Online Installer 無法下載

`online-setup.exe` 第一次使用需要下載：

- OKSS
- Python
- Python 套件
- 其他執行環境

如果下載失敗，可以檢查：

- 網路連線
- 防火牆
- VPN
- 防毒軟體
- GitHub 是否可以正常存取
- Python 套件下載服務是否被阻擋

如果無法解決，建議改用 Global 完整安裝版本。
