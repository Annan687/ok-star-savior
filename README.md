# OKSS · 星之守護者日課

Star Savior 繁體中文 PC 版日課助手，使用 [ok-script](https://github.com/ok-oldking/ok-script) 框架及 [PyAppify](https://github.com/ok-oldking/pyappify) 安裝器。

## 安裝與開始

1. 從此專案的 Releases 下載 `ok-star-savior-win32-Global-setup.exe`，依安裝精靈完成安裝。Global 是已備妥執行環境的版本；`online-setup.exe` 首次啟動需要連網下載程式、Python 與套件。
2. 開啟 Star Savior，使用繁體中文並回到大廳；再開啟 OKSS。
3. 在「遊戲連線」選擇 StarSavior.exe，按「檢查遊戲畫面」確認擷取正常。
4. 選擇自己要執行的日課及刷關目標，再按「開始日課」。首次設定不消耗體力，限時據點預設略過。

不需要另外安裝 Python。使用 Windows 10／11 的 64 位元環境。保持 16:9； 1920×1080 已實測，1600×900 符合尺寸限制但仍需自行檢查辨識。

## 操作方式

目前使用前台滑鼠輸入，執行時保持遊戲在前台，避免同時移動滑鼠或操作其他視窗。

17 項日課包括登入彈窗、支援金、郵件、好友點數、免費禮包與指定商店商品、探索免費券、體力刷關、立方、限時據點、屬性迴廊、策略戰、活動、任務、派遣、公會及通行證。

勾選商店與公會項目會依既定規則購買商品或捐獻遊戲資源：啟示錄兩種五折商品買 MAX、公會購買星光石、捐黃金及活動證明；策略戰允許免費或黃金刷新。體力刷關只使用現有體力，不購買體力或使用回復道具。請先閱讀並選擇需要的項目。

## 更新與紀錄

PyAppify 使用此專案的版本標籤檢查更新。更新後仍沿用各使用者本機設定。

`configs` 保存設定；`runs`、`logs` 和 `screenshots` 保存本機執行紀錄與異常畫面，不自動上傳。回報問題前請檢查附檔是否含有帳號資訊。

## 測試版範圍

目前已在一個帳號進行前台日課實測並修正，測試包含分段續跑。不同帳號的解鎖進度、新活動及介面更新可能需要再校正；遇到未知畫面會停止並保留原因。

完整安裝器首次建置和另一台電腦的乾淨安裝仍須驗證；原始碼準備完成不代表安裝檔已發佈。
